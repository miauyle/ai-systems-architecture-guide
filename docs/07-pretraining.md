# 07 · 数据与预训练架构

[返回目录](../README.md) · [下一章](08-post-training.md)

## 预训练将什么信号变成参数

语言模型的下一 Token 目标，把语料中的前缀与后继作为监督信号。网络前向产生词表分数，损失比较目标 Token 的概率，反向计算各参数对损失的影响，优化器据此改变权重。它不是把所有句子逐条塞进 KV 或文档索引。

目标形式简单，但要降低损失，模型可能需要学会语法、实体关系、代码结构与任务模式。预测准确不保证事实可靠、符合用户意图或有执行权限；后训练与应用负责其他约束。

## 数据怎样进入一次前向

原始资料先经过授权与来源记录、解析、过滤、去重和版本化，再 Tokenize、按配比采样、形成序列或打包批次。存储里的文档对象与训练所见的 Token 顺序并不一一相同，必须保存两者的可追溯关系。完整数据生命周期见[第 15 章](15-data-lifecycle.md)。

每个训练批次至少要正确提供 Token IDs、位置/序列边界、可见性 Mask 与监督位置。这几种字段承担不同职责：

| 字段 | 决定什么 | 典型错误 |
| --- | --- | --- |
| 输入 IDs | 哪些内容参与前向 | 数据清洗或切分改变关键结构 |
| 位置与序列边界 | 顺序从哪里继续，哪些位置属于同一段 | 打包后把不同样本当成同一文本 |
| Attention Mask | 哪些输入能互相读取 | 目标泄漏或不必要的跨文档读取 |
| Loss Mask / 标签 | 哪些后继预测参与损失 | 将 padding 或不应监督的片段计入目标 |

拼接文档时可以用边界 Token，并按设计允许跨文档上下文，也可以使用独立片段的块状因果 Mask；二者的训练分布不同。仅放一个 EOS 不自动屏蔽注意力。位置是否重置也必须与模型和边界设计一致。

## 输入与标签错开，但不需要逐步生成

对原始序列 `x0,x1,…,xT`，一种表示是输入 `x0,…,x(T-1)`，各输入位置的目标分别是 `x1,…,xT`。也有接口接收完整 IDs 并在内部移位；调用方不能再移位一次。

所有输入位置已知，网络可以在同一前向处理它们。因果 Mask 使位置 `t` 不读取目标位置 `t+1`，这就是 Teacher Forcing 下的并行监督。训练不必先采样模型输出再喂给下一位置；生成时则没有完整答案可用。

logits 在词表轴上计算 Log-Softmax，并取真实后继 ID 的对数概率。Loss Mask 决定哪些位置计入聚合，padding 应排除，分母应与有效监督位置一致：

```math
\mathcal{L}=-\frac{1}{N_{valid}}\sum_{(b,t)\in valid}\log p_\theta(x_{b,t+1}\mid x_{b,\le t})
```

一个输入位置不计自己的预测损失，不意味着它不参与学习：后面受监督的输出可能通过 Attention 依赖它，梯度仍能通过其表示和相关共享参数传播。Loss Mask 与 Attention Mask 不能混为同一个开关。

## 损失如何沿网络回到参数

末端损失对 LM Head 与末层隐藏状态产生梯度，再通过 FFN、残差、归一化、Attention 回到此前各层。Attention 反向需要知道哪些键和值影响输出，投影反向累积对应权重梯度；Embedding 的被使用行也得到梯度。

同一权重在多个位置复用，各位置贡献需累加。一个参数的梯度表示当前批次下的局部变化方向，不等于一个可以逐条读出的“新知识条目”。优化器更新后，下一步才使用新权重。

前向中部分激活和统计量要留给反向；也可在反向时重计算，以计算换内存。训练的历史激活不是推理 KV Cache：权重会更新，跨训练步骤通常不能复用旧前向的 K/V。执行循环、混合精度与分布式同步见[第 17 章](17-training-engineering.md)。

## 为什么训练占用不只是模型权重

训练通常还要保存梯度、优化器一阶/二阶矩，以及反向所需激活和临时缓冲。不同对象随不同量增长：参数状态随参数量增长，激活随批次、长度、宽度、层数及保存策略增长。

长序列同时影响激活、注意力工作和有效监督 Token；用重计算降低保存状态不减少输入信息，也不保证总耗时下降。分布式训练能分片一些对象，但运行时仍可能临时汇集完整计算单元，不能简单把全部显存除以卡数。

## 数据配比、去重与评估之间的关系

采样混合决定训练中各类内容的出现概率。提高代码、语言或领域数据比例，会改变梯度来源和能力取舍，不是只扩大目录。训练后期分布变化和重复训练次数也会影响结果。

精确去重可比较规范化后的内容哈希，近似去重可寻找重复片段或高相似文档；规范化过强也可能把有效差异抹掉。跨训练集与评估集的污染检查要覆盖重复题面、答案、转载和变体，否则指标可能主要反映见过资料。

去重、质量和配比需要与评估按数据版本关联。更低训练损失可能来自更容易的数据或重复，不应直接当成更强的泛化。学习与泛化的区分见[第 23 章](23-machine-learning-foundations.md)。

## 计算预算约束的是完整模型寿命

参数量、有效训练 Token 和训练计算共同约束资源；规模规律提供经验关系，其结论依赖架构、数据、优化与预算。粗略 FLOPs 估算不包含全部数据准备、通信、检查点和硬件利用率。

一个模型还要长期推理。更大模型可能每次生成更贵，更长训练可能增加前期成本却改善固定模型的质量；决策要看训练与预计使用的总成本，而不是只看单次训练最优点。研究依据：[Compute-Optimal Training](https://arxiv.org/abs/2203.15556)。

## 产物怎样进入下一阶段

可恢复检查点包含权重、优化器/调度状态、全局步数、随机状态和数据进度；发布模型通常只包含推理需要的资产，不等于可无损恢复训练。Tokenizer、配置与输入约定必须一起版本化。

后训练从这些资产继续改变参数或适配器，Serving 则加载固定版本执行请求。训练数据、检查点与发布版本之间的关系见[模型生命周期](26-model-lifecycle.md)，检查点一致性见[训练系统](17-training-engineering.md)。
