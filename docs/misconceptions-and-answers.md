# 常见误区与自测答案

[返回目录](../README.md)

## 十个容易踩的坑

| 误区 | 正确理解 |
| --- | --- |
| 参数越多一定越强 | 数据、训练、架构、后训练和具体任务共同决定效果 |
| 上下文越长就能完美利用所有资料 | 输入容量、位置机制、训练分布和有效检索能力都重要 |
| 预训练就是保存一个可查询数据库 | 参数学习分布式规律，也可能记忆；事实访问不保证准确或可追溯 |
| KV Cache 就是答案缓存 | 它保存每层历史 K/V 张量 |
| 4-bit 模型的所有内存都变成原来的四分之一 | 激活、缓存、元数据和未量化模块不一定同比例下降 |
| MoE 只需存储当前激活的专家 | 所有专家权重仍要存储或被可访问地卸载 |
| Attention 权重就是模型完整思考过程 | 只是信息流的一部分，不是完整因果解释 |
| RAG 可以消除所有幻觉 | 检索、来源、上下文和生成每层都可能出错 |
| 微调最适合持续更新制度事实 | 频繁变更和引用要求通常优先考虑外部检索 |
| Agent 越自主越有用 | 自主范围增加复杂性，需按任务成功率和成本判断 |

## 01 · 全景

1. RAG 通常更新外部文档与索引，不必更新生成模型权重。
2. 参数规模是模型容量的一种描述；上下文长度是序列长度约束；并发是服务负载与资源调度概念。
3. 权重没有内置业务系统当前的用户授权状态，必须由数据访问与应用系统实现权限。

## 02 · 数学

1. 输出为 `[2,10,32]`，只改变最后一维。
2. Softmax 形成候选分布；RMSNorm 调整隐藏状态尺度，服务于网络计算稳定性。

## 03 · 表示

1. Token 数取决于具体 Tokenizer；上下文还包含角色模板、指令、历史与输出预算。
2. 不能默认互换。训练目标、池化或多向量表示、归一化与检索空间可能不同。

## 04 · Transformer

1. Attention 汇总其他允许位置的信息；典型 FFN 对每个位置独立变换，但其输入已含上下文。
2. 训练目标序列已知，可并行计算并用因果 Mask 阻止偷看；生成时新 Token 依赖前面的实际生成结果。
3. 模型需要为整个词表给分，再由解码算法选 Token，Token 也未必是一个汉字。

## 05 · Attention 手算

1. 若有 $`n`$ 个允许键且分数相同，每个权重为 $`1/n`$。
2. 不一定。K 用于匹配、V 用于传递内容，来自不同投影。

## 06 · 架构变体

1. GQA 减少 K/V 头数，主要改善 KV Cache 容量和相关读写带宽。
2. 每个 Token 只使用部分专家，且总计算还包含共享层、路由和通信。
3. FlashAttention 优化计算与内存访问；滑窗改变能访问哪些位置，因此改变注意力结构。

## 07 · 预训练

1. Attention Mask 控制信息可见性；Loss Mask 控制哪些输出位置参与损失。
2. 只加载权重缺少优化器状态、调度进度和随机状态等，后续轨迹可能不同。
3. 不能。业务任务还要检验事实、证据、权限、服务和用户验收。

## 08 · 后训练

1. SFT 描述训练信号；LoRA 描述用哪些增量参数学习，两者可以组合。
2. 不一定，经典 DPO 直接使用偏好对与参考模型构造目标。
3. 外部资料容易更新、按版本检索并给出处，不需要每次改动都重训权重。

## 11 · 应用

3. 不证明。来源可能错误、过期，或未支持具体断言。

## 12 · 评估

1. 不保证，错误上下文、信息冗余和生成失误仍可能降低正确率。
2. 模型裁判存在风格与顺序等偏差，也可能误判事实，需要人工校准。
3. 版本和数据变化会改变结果；记录它们才能复现与归因。
