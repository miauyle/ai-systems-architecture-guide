# 05 · 手算一次 Attention

[返回目录](../README.md) · [下一章](06-modern-architectures.md)

## 教学设置

三个位置，每个头的维度为 2。下面的 Q/K/V 是人工构造的演示数据，不是某个真实模型提取出的向量。

计算第三个位置的注意力：

$$
q_3=[1,0],\quad k_1=[1,0],\quad k_2=[0,1],\quad k_3=[1,1]
$$
$$
v_1=[10,0],\quad v_2=[0,10],\quad v_3=[5,5]
$$

可以把它理解为：查询与三把键比较相似程度，再按比较结果混合三份值。

## 第一步：相似度与缩放

点积得到 $[1,0,1]$，除以 $\sqrt{2}$ 得到约 $[0.7071,0,0.7071]$。

第三个位置可看见前三个位置，因此这一次没有需要屏蔽的键。

## 第二步：Softmax

$$
[e^{0.7071},1,e^{0.7071}]\approx[2.0281,1,2.0281]
$$

归一化后的权重约为：

$$
[0.4011,0.1978,0.4011]
$$

这里 $k_1$ 与 $k_3$ 和查询的点积相同，因此得到相同权重。它们的值向量仍然不同。

## 第三步：汇总 V

$$
z_3=0.4011[10,0]+0.1978[0,10]+0.4011[5,5]
$$
$$
z_3\approx[6.0167,3.9833]
$$

这就是一个头的输出。实际多头模型还需要拼接各头、输出投影、残差连接和后续子层。

## Mask 改变什么？

再考虑第二个位置的另一个查询 $q_2=[0,1]$。未屏蔽时缩放分数为 $[0,0.7071,0.7071]$。

因果注意力不允许第二个位置读取第三个位置，所以改为 $[0,0.7071,-\infty]$。Softmax 约为 $[0.3302,0.6698,0]$，输出约为 $[3.3024,6.6976]$。

Mask 在 Softmax 前作用，使允许位置的权重重新归一化。不能先用所有位置算好加权平均，再删掉未来位置的影响。

## 为什么分开 K 与 V？

「用什么特征匹配」和「把什么信息传过去」可以不同。K 参与匹配，V 参与内容组合，让模型能够分别学习这两类投影。

Attention 权重能帮助检查信息流，但仅凭权重大小不能证明模型答案的完整因果解释；其他头、残差和 FFN 也影响输出。

## 不依赖第三方库的复算

```python
import math

q = [1.0, 0.0]
keys = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
values = [[10.0, 0.0], [0.0, 10.0], [5.0, 5.0]]
scores = [sum(a * b for a, b in zip(q, k)) / math.sqrt(2)
          for k in keys]
offset = max(scores)
exp_scores = [math.exp(s - offset) for s in scores]
weights = [e / sum(exp_scores) for e in exp_scores]
output = [sum(w * v[j] for w, v in zip(weights, values))
          for j in range(2)]
print(weights)
print(output)
```

预期输出约为 `[0.4011, 0.1978, 0.4011]` 和 `[6.0167, 3.9833]`。运行方法见[动手实验](15-experiments.md)。
