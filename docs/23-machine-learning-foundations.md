# 23 · 机器学习、表示学习与泛化

[知识地图](00-learning-roadmap.md) · [数学与张量](02-math-and-tensors.md) · [预训练](07-pretraining.md)

## AI、机器学习与深度学习的关系

人工智能包含使系统完成感知、判断、规划和行动的多种方法，既有学习方法，也有搜索、规则与优化。机器学习通过数据和目标函数调整模型；深度学习使用多层可学习变换形成表示。大语言模型属于深度学习的一条重要路线，不能代表 AI 的全部。

这个关系影响系统选择。精确规则、结构化查询和约束求解已有明确机制时，可以直接使用程序；需要从复杂输入中归纳模式时，学习方法更有价值。真实系统常把两者组合，让模型处理不确定的感知和语言，让程序承担明确的约束与状态转换。

## 一个学习问题由什么定义

学习任务至少包含输入、目标、可用数据分布、模型假设、损失和评估标准。分类预测类别，回归预测数值，排序组织候选顺序，生成产生新的结构或序列。相同输入可以支持不同任务，选择的损失会改变模型学什么。

训练优化的是可计算目标，用户关心的是实际任务。例如下一 Token 损失衡量文本预测，不能直接证明回答真实；点击预测可以提高点击率，却未必改善长期满意度。目标与业务需求之间的差距，是系统设计的一部分。

| 学习范式 | 数据提供什么 | 学习信号从哪里来 | 系统中的典型用途 |
| --- | --- | --- | --- |
| 监督学习 | 输入及对应目标 | 标签与预测差异 | 分类、抽取、回归、SFT |
| 自监督学习 | 主要是原始数据 | 从数据本身构造目标 | 语言预测、掩码恢复、表示预训练 |
| 无监督学习 | 无人工任务标签的数据 | 结构、密度或聚类目标 | 聚类、异常探索、分布建模 |
| 强化学习 | 状态、动作与反馈 | 交互奖励及长期回报 | 控制、策略优化、部分模型后训练 |

自监督仍然有训练目标，只是不要求人工逐项标注。强化学习也不是给回答附一个分数就完成了：还涉及采样分布、动作选择与信用分配。

## 参数、超参数与模型选择

参数由训练调整，包括权重与偏置；超参数描述结构、训练和正则化选择，例如层数、学习率和数据配比。超参数可能通过搜索或自动方法选择，但它们与一次普通反向传播更新的对象不同。

模型结构限定可表达的计算关系，训练数据决定看到什么，优化决定走到哪组参数。一个模型表现差，可能是输入缺乏所需信息、结构不适合、数据分布不匹配，也可能是优化没有成功。扩大参数量只能触及其中一部分。

## 表示学习为何重要

传统流程常由人工设计特征，再交给模型预测；深度网络让特征提取与任务目标共同优化。Embedding、视觉编码器与深层隐藏状态都属于这种可学习表示。

表示好不好取决于用途。用于生成的表示强调预测序列，用于检索的表示强调查询与资料之间的排序，用于分类的表示强调标签边界。它们可能共享基础能力，却不能因“都是向量”就直接互换。

迁移学习利用已有表示适配新任务。冻结编码器只训练小头，资源需求较低，但适应能力受已有表示限制；全量微调能改变整个网络，也更容易过拟合并需要更多状态。LoRA 是调整参数方式，SFT 是目标与数据形式，两者可以组合。

## 经验风险与泛化

训练只能观察有限样本，通过样本损失近似真实分布上的风险。训练集成绩描述对已见数据的拟合，测试集成绩在合理划分下提供对目标泛化的证据，两者不是同一个问题。

过拟合表现为学到训练数据的偶然细节或噪声，而缺乏迁移。欠拟合表示模型、特征或优化不足以捕获任务结构。训练损失下降而验证变差是重要线索，但不能单凭曲线确定原因，还要看划分、标签和分布。

正则化、数据增强、早停和混合数据都影响泛化。数据增强必须保持任务语义：改变图片视角可能合理，改变关键数值或否定条件却可能改变答案。更多数据也必须带来合适的覆盖，而不是增加同一模板的重复。

## 数据泄漏与评估污染

泄漏是预测时不可获得的信息进入训练或评估流程。它可能来自未来时间、同一用户重复样本、标签派生特征、检索上下文中的参考答案，或公开题库被模型训练使用。

测试集若持续被用于挑模型、调 Prompt 和修改索引，就承担了验证集的角色，最终成绩不再是独立检验。应保留独立留出集，并明确公开基准可能存在的污染限制。

数据划分单位应对应希望验证的迁移：新时间、新用户、新领域或新问题组合。随机按行切分只是其中一种方法。[数据生命周期](15-data-lifecycle.md)展开内容家族与版本管理。

## 分布变化与上线失效

输入分布变化、标签比例变化、输入与目标关系变化，会造成不同类型的失效。换了文档模板可能破坏解析，出现新产品可能改变检索术语，制度更新则改变正确答案本身。

线上退化不一定需要立即训练新模型。先定位数据、处理、知识、模型还是执行链发生变化，再选择重新标注、重建索引、调整阈值或后训练。对已知适用边界之外的任务，还需要澄清或回退。

## 不确定性、置信度与校准

输出概率来自训练与模型假设，并非天然正确率。模型可以对错误输出给出高概率；语言中说“我很确定”更加不能直接解释成统计概率。

校准关注某一类置信度下实际正确比例是否匹配。校准的用途包括阈值决策和风险分层，但它也依赖任务与分布，换领域后可能失效。生成任务的序列概率、事实支持和最终任务成功是不同对象，需要分别判断。

## 传统方法仍有系统价值

线性模型、树模型、聚类、推荐排序和异常检测可以解决结构化数据任务，通常具有不同的成本和可解释性特点。神经网络并不自动替代这些方法，LLM 也不适合承包所有数字预测。
