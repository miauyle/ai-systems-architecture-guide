# 02 · 只补齐必要的数学与张量知识

[返回目录](../README.md) · [下一章](03-tokenization-and-embeddings.md)

## 数字怎样组织

标量是一个数，向量是一列特征，矩阵是一批向量，张量是推广到更多维度的数组。维度代表的语义比名字更重要。

本仓库统一采用：

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `B` | 批大小 | 2 个请求 |
| `T` | Token 数量 | 每个序列 128 个 Token |
| `d` | 隐藏维度 | 每个位置 512 个数 |
| `V` | 词表大小 | 32,000 种 Token |
| `L` | 网络层数 | 12 层 |
| `h`、`d_h` | 注意力头数、每头维度 | 8 头，每头 64 维 |

隐藏状态 $`X`$ 的常见形状是 $`[B,T,d]`$。第一维找到样本，第二维找到位置，第三维找到该位置的特征。

## 矩阵乘法：学会混合特征

对一个位置，$`x\in\mathbb{R}^{1\times d}`$，权重 $`W\in\mathbb{R}^{d\times m}`$，则 $`xW\in\mathbb{R}^{1\times m}`$。每个输出特征是多个输入特征的加权和。

它不是把某个特征明确命名为「语法」或「事实」。可解释的语言特征可能分布在很多维度，不能随意给每一维贴标签。

线性变换后通常还需要非线性激活函数；否则多层线性变换可以合并成一个线性变换，表达能力受限。

## Softmax：把分数变成分布

```math
\mathrm{softmax}(z)_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
```


Softmax 的输出为正且总和为 1。实现时通常先减去最大值改善数值稳定性，这不改变结果。

如果 logits 为 $`[2,1,0]`$，概率约为 $`[0.665,0.245,0.090]`$。最大的 logit 最受偏好，但是否最终选它取决于解码方式。

## 损失与梯度：如何学

若正确 Token 的概率是 $`p`$，单位置交叉熵损失为 $`-\log p`$。若 $`p=0.8`$，损失约为 0.223；若 $`p=0.1`$，约为 2.303。损失奖励模型给正确目标更高的概率。

梯度表示参数微小变化怎样影响损失。简单梯度下降为：

```math
\theta\leftarrow\theta-\eta\nabla_\theta\mathcal{L}
```


实际大模型常用 AdamW 等优化器，有额外状态和训练技巧。反向传播是高效计算梯度的方法；优化器决定怎样用梯度更新参数。

## 残差与归一化

残差连接形如 $`y=x+f(x)`$，让子层在已有表示上增加修正，也有利于深层网络优化。维度必须兼容。

归一化控制激活尺度，改善数值和训练稳定性。LayerNorm 和 RMSNorm 的计算不同：RMSNorm 通常使用均方根缩放，不像 LayerNorm 那样减均值。它们都不是把模型输出变成概率。

## 最低数学要求

现在只需能读懂形状、矩阵乘法、加权平均、Softmax 和损失。概率、微积分、数值优化可以随着训练章节补充，不必先把整本数学教材读完。

## 概率链式分解为什么能支持生成？

联合概率可以按条件概率逐步分解。模型不用一次列举全部可能句子，只需在每一步估计下一个 Token 的分布。连续选择 Token 的过程对应序列概率的因子逐步确定。

训练常把序列概率的乘积转成对数概率的和，避免很小的概率连乘导致数值下溢，也方便按位置计算损失。自然对数下，交叉熵是以 nat 为单位；换用其他底数会改变数值尺度。

## 交叉熵梯度的含义

Softmax 和交叉熵组合后，对每个 logit 的导数等于预测概率减去目标指示。预测越偏离目标，更新信号越明显；正确项提高，其他项降低。

若目标有噪声，优化器仍会按这个信号学习，所以训练过程本身不会自动辨认所有错误标签。细节与手写梯度实验见[训练系统详解](17-training-engineering.md)。

## 归一化具体在什么范围计算？

对隐藏状态 `[B, T, d]`，常见 LayerNorm 沿最后的 d 维计算每个位置自己的均值与方差，不跨样本汇总。BatchNorm 的统计范围与行为不同，不能把二者只当成同一种「标准化」。

LayerNorm 的教学形式如下；真实模块还可以有可学习缩放与偏移：

```math
y_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}
```

ε 避免方差接近零时除法不稳定，具体数值与框架和精度有关。RMSNorm 改用均方根，不减均值；其归一化不把元素和变成 1。

## 梯度、雅可比与反向传播怎样联系？

一层的输出可能有许多维，完整雅可比描述每个输出对每个输入的导数。但训练通常不需要显式存整个雅可比，反向传播沿链式法则计算损失对参数的向量—雅可比乘积。

这也是自动微分框架会记录计算所需状态的原因。原地修改关键激活、切断计算图或忘记开启参数梯度，可能让反向计算错误或消失，即使前向输出看起来正常。
