# 第 4 课：从一个注意力层到完整 Decoder 与训练流程

[课程目录](README.md) · [上一课](03-context-and-attention.md) · [下一课：生成与服务](05-generation-and-serving.md)

上一课训练了一个读取上下文的模型。它只有单头注意力和输出层。本课逐个补齐完整 Decoder 的组件，然后跟踪一条对话数据怎样成为训练信号。先理解各组件解决的计算问题，再接触架构变体和后训练方法。

## 1. 一个可计算的 Decoder Block

采用常见的 PreNorm 结构。H 表示这一层输入：

```math
U=H+\mathrm{Attention}(\mathrm{Norm}(H))
```

```math
H_{\mathrm{next}}=U+\mathrm{FFN}(\mathrm{Norm}(U))
```

首先对表示归一化，再计算注意力并加回原输入；接着归一化，经过前馈网络，再加回。这是一个具体结构，不是所有 Transformer 的唯一排列；PostNorm、Norm 类型、激活与位置实现可以不同。

### 残差：保留直接的信息与梯度通路

假设新计算结果完全不可靠，残差仍把 H 加到下一层。反向传播时，`H+F(H)` 的导数含有恒等项，梯度除了经过 F，还能沿直接路径传播。这有利于深层优化，但不保证无限堆叠不会出现不稳定。

### 归一化：控制单个位置的特征尺度

LayerNorm 对每个位置的 d 个特征计算均值 μ 和方差，标准化后再乘可学习缩放、加偏移：

```math
\hat h_i=\frac{h_i-\mu}{\sqrt{\sigma^2+\epsilon}},\qquad y_i=\gamma_i\hat h_i+\beta_i
```

它不沿时间轴混合位置，也不使用未来 Token。`[1,3]` 的均值为 2，方差为 1，忽略 ε 后得到 `[-1,1]`。RMSNorm 使用均方根尺度、不减均值；计算与参数细节见架构专题。

### FFN：在单个位置变换特征

普通两层前馈网络为：

```math
\mathrm{FFN}(h)=\phi(hW_1+b_1)W_2+b_2
```

W1 通常扩张维度，非线性函数 φ 改变特征关系，W2 映射回模型宽度。Attention 在位置之间传信息；FFN 对每个位置的特征进行计算，参数跨位置共享。

如果两层之间没有非线性，两次矩阵乘法可以合成一次线性变换，表达能力受限。现代模型常用门控 FFN，例如 SwiGLU，这会改变投影数量和参数估算。

## 2. 多头如何从一个矩阵变出来

设模型宽度 d=16，头数 h=4，每个头维度 dh=4。投影后的 Q 起初是 `[B,T,16]`；先 reshape 为 `[B,T,4,4]`，再转置为 `[B,4,T,4]`。

每个头独立计算 `[T,T]` 匹配矩阵，得到自己的 `[T,4]` 输出，再拼回 `[B,T,16]` 并通过输出投影。不同头可以学习不同信息路由，但不能事先宣称“第一个头负责语法、第二个负责事实”。

GQA 让多个 Query 头共享较少的 K/V 头，主要改变 K/V 投影和缓存尺寸；MoE 把部分 FFN 换成路由到若干专家的结构。这些改动都可以落回“哪个张量、哪些参数、多少计算”来理解。

## 3. 从一层到整个语言模型

```text
Token IDs [B,T]
  → Token Embedding + 位置信息 [B,T,d]
  → Decoder Block 1
  → Decoder Block 2
  → …
  → 最终归一化
  → 词表投影 [B,T,V]
  → 按位置计算 softmax / 交叉熵
```

层层堆叠后，早期表示会被反复重组。深层缓存中的 Key/Value 不是原始 Token Embedding，而是该层对已有上下文表示的投影。

在简化的普通 FFN、Q/K/V 同宽、无偏置、每层扩张倍数 4 的配置中，一层参数约为 `4d²+8d²=12d²`：四个注意力投影与两个 FFN 矩阵。L 层约 `12Ld²`，再加 Embedding、输出层与归一化。门控 FFN、GQA、MoE、权重共享会改变这个公式，不能按它反推所有模型。

## 4. 跟踪可运行完整前向

```bash
python examples/transformer_numpy.py
```

程序配置为词表 32、宽度 16、4 个头、2 层、FFN 宽度 32。读取其 `forward`，对照前面的形状。在这个实现中，FFN 扩张倍数是 2，Norm 没有可学习仿射，不能套用上面倍数为 4 的参数估算。

验证先让完整前缀一次经过模型，再逐 Token 输入并复用缓存。最后的 logits 应在浮点误差范围内一致。另一个检查改变未来 Token，验证早期位置 logits 不变，这直接检查因果性。

程序是随机权重，没有反向传播和语言训练。它用于理解多头、堆叠、因果掩码、位置偏移和缓存；第三课的训练程序则用于理解参数学习。将完整 Decoder 的算子全部接入自动微分后，可用相同的损失训练，但规模、数据与数值稳定性会成为新的问题。

## 5. 对话如何变成输入与标签

考虑一条教学对话：

```text
用户：上海住宿上限多少？
助手：每人每晚800元。
```

真实训练必须使用与推理一致的聊天模板，明确角色、分隔符、结束标记等。下面用符号化 Token 展示计算，实际分词长度不同：

| 位置 | 输入 Token | 该位置预测目标 | 若只监督助手回答，是否计损失 |
| --- | --- | --- | --- |
| 0 | BOS | USER | 否 |
| 1 | USER | 问题内容 | 否 |
| 2 | 问题内容 | ASSISTANT | 否，按本例约定 |
| 3 | ASSISTANT | 回答内容 | 是 |
| 4 | 回答内容 | EOS | 是 |

输入仍包含用户问题，用户内容也参与产生助手预测的表示；“不计用户位置损失”不意味着把用户问题从 Attention 中屏蔽。

损失掩码与注意力掩码是两个对象。前者决定哪些预测计入优化目标，后者决定哪些输入位置可互相读取。错误混用会造成回答看不到问题，或者训练偷看目标。

## 6. 长度不一的样本怎样组成批次

样本 A 有 2 个有效监督 Token，样本 B 有 6 个。假设它们损失之和分别为 2 和 3：按有效 Token 平均是 `(2+3)/(2+6)=0.625`；先算每条样本均值再平均则是 `(1+0.5)/2=0.75`。两种目标权重不同，必须明确选择。

Padding 补齐长度，但不能贡献训练损失。Packing 把多段文本装进同一序列，提高利用率；若希望独立样本互不访问，需要设置跨段注意力边界。把样本直接拼起来却不说明边界，会改变训练目标。

验证集也要按同样的标签和平均规则计算。只比较打印出的数字，而不知道分母是样本还是 Token，容易误判改进。

## 7. 预训练、SFT、偏好学习到底改变哪一环

**预训练**通常在大量文本上预测下一 Token，数据覆盖决定学到的分布范围。去重、质量过滤、污染检测、语料比例都会改变训练信号。架构正确并不能弥补错误或泄漏的数据。

**监督微调 SFT**换成任务或对话样本，常只监督助手回答。基础机制仍是 Token 交叉熵；数据分布与标签范围改变了。

**偏好学习**比较同一个问题的较好与较差回答。DPO 根据策略相对于参考模型的回答对数概率差构造目标；它不是“只对好答案做 SFT”。奖励模型与强化学习方法则加入采样、奖励与策略更新等步骤。具体推导进入后训练专题。

**LoRA**改变哪些参数可训练：令一个矩阵更新为低秩的 `ΔW=BA`，固定基础 W，只学习较小的 A、B。它是参数适配方法，可以配合 SFT 或其他目标，并不与 SFT 构成互斥选项。

**RAG**在推理时提供外部证据，不直接更新模型权重。它解决“当前有什么信息可以访问”，第六课会实现其读取链路。

## 8. 训练为何比加载权重占更多内存

训练不仅保存权重，还要保存反向需要的激活、梯度和优化器状态。若采用一种假设配置：BF16 权重 2 字节、梯度 2 字节、FP32 主权重 4 字节、Adam 两个 FP32 状态共 8 字节，总计约 16 字节/参数，尚未计算激活和临时空间。

一亿参数的这些状态约 `1.6 GB` 十进制。不同框架可能不保留单独主权重，或使用不同状态精度；应查实际实现。激活检查点通过反向时重新计算部分前向，减少存储并增加计算。ZeRO/FSDP 分片的是不同训练状态，不是让这些状态凭空消失。

## 9. 练习与解析

**练习 1。** 删除 FFN，只保留 Attention 和输出层，仍是完整的本课 Decoder 吗？

**解析。** 仍是可学习的注意力模型，但不是这里定义的完整 Decoder Block。第三课就是这样的简化；不能把其结果描述为完整 Transformer 已训练完成。

**练习 2。** 用户位置不计 loss，是否意味着对应 Embedding 没有梯度？

**解析。** 不意味着。助手的预测可以通过注意力读取用户位置，因此助手损失会沿这条计算路径传回用户 Token 的表示与共享参数。

**练习 3。** 语料重复一百次，验证损失很低，能否证明模型泛化更好？

**解析。** 不能。重复会改变采样权重，训练与验证若存在重复又会泄漏。应按文档或来源划分，再检查独立任务和分布之外的样本。
