# 第 2 课：从概率到参数，手算一次真正的学习

[课程目录](README.md) · [上一课](01-prediction.md) · [下一课：注意力](03-context-and-attention.md)

上一课明确了训练目标：让真实下一 Token 的概率提高。本课建立整条计算链：Token ID → 向量 → logits → 概率 → 损失 → 梯度 → 参数更新。每个环节都有可以检查的数值或形状。

## 1. 索引为什么要变成向量

Token ID 是索引，不能直接拿编号距离代表语义。设词表大小为 4，向量维度为 2，Embedding 表为：

```text
E = [[ 1, 0],    # 甲
     [ 0, 1],    # 乙
     [-1, 0],    # 丙
     [ 0,-1]]    # 丁
```

输入 ID 为 `1` 时，取出第二行 `[0,1]`。这称为查表，不是把整数 1 当作连续数值特征。学习过程中矩阵中的每个元素都可以改变；上面只是为了计算方便的初始值。

也可以用 one-hot `[0,1,0,0]` 左乘 E，得到相同结果。实际实现直接索引，避免为大词表构造多数元素为零的矩阵。

## 2. 矩阵乘法如何得到一个预测

假设当前向量 `x=[1,2]`，输出词表暂时只有三个候选。输出矩阵：

```text
W = [[2, 1, 0],
     [0, 0, 0]]
```

`x @ W` 的结果是 `[2,1,0]`。第一列与 x 的点积是 `1×2+2×0=2`，第二列得到 1，第三列得到 0。结果称为 logits：它们是任意实数评分，不是概率，也不要求总和为 1。

批量输入时，若 X 为 `[B,d]`，W 为 `[d,V]`，结果就是 `[B,V]`。`B` 是样本数，`d` 是向量维度，`V` 是词表大小。维度不仅帮助检查程序，也说明一个参数会在哪些样本中被重复使用。

语言模型经常处理 `[B,T,d]`：每个样本有 T 个位置，每个位置一个 d 维向量。对最后一维应用同一个输出矩阵，得到 `[B,T,V]`。

## 3. softmax 把评分变成概率

```math
p_i=\frac{\exp(z_i)}{\sum_j\exp(z_j)}
```

对 `[2,1,0]`，指数为约 `[7.3891,2.7183,1]`，归一化得到 `[0.66524,0.24473,0.09003]`。

实现不能对任意大 logits 直接取指数。先减去这一行的最大值，变成 `[0,-1,-2]`，再取指数，得到相同概率。这是因为分子分母都被乘了同一个缩放因子。

```python
shifted = logits - logits.max(axis=-1, keepdims=True)
exp = np.exp(shifted)
probability = exp / exp.sum(axis=-1, keepdims=True)
```

`axis=-1` 表示沿候选类别归一化。若误沿 batch 维归一化，样本之间会互相影响，每个样本的候选概率也不再正确。

计算损失时最好直接使用 log-softmax：`shifted - log(sum(exp(shifted)))`。对极低概率先算 softmax 再取 log，可能得到 `log(0)`。

## 4. 导数回答“往哪个方向改变”

对函数 `f(w)=w²`，把 w 改动一个很小的量 ε：

```math
\frac{(w+\epsilon)^2-w^2}{\epsilon}=2w+\epsilon
```

ε 趋近于零时结果为 `2w`。这表示在当前 w 附近，参数每增加一小步，函数会以多快的速度增大。梯度把这个概念扩展到多个参数，每个分量对应一个参数的局部影响。

训练用梯度下降更新：

```math
\theta_{\mathrm{new}}=\theta_{\mathrm{old}}-\eta\nabla_{\theta}L
```

学习率 η 决定每次走多远。导数是局部近似，不保证任意大一步都会降低损失；学习率过大可能跳过低损失区域。

## 5. softmax 与交叉熵的梯度为什么是 p−y

真实目标为第 k 个类别时，损失可以改写为：

```math
L=-z_k+\log\left(\sum_j\exp(z_j)\right)
```

第一项只对真实类别贡献 `-1`；第二项对每个 logit 的导数是该类别的 softmax 概率。因此：

```math
\frac{\partial L}{\partial z_i}=p_i-y_i
```

`y` 是真实目标的 one-hot 向量。沿用 `[2,1,0]`，假设真实目标是第二个候选，则 y 为 `[0,1,0]`，梯度为 `[0.66524,-0.75527,0.09003]`。

把 logits 当作独立参数，用学习率 `0.1` 更新，得到约 `[1.93348,1.07553,-0.00900]`：错误类别降低，真实类别提高。真实目标损失原本 `1.40761`，更新后约为 `1.30735`。

真实模型不会直接保存每个样本的 logits。它更新生成 logits 的共享参数，所以下一步要把梯度继续传回 W 和 x。

## 6. 链式法则把局部梯度接起来

若 `z=xW`，则：

```math
\nabla_W L=x^{\mathsf T}\nabla_z L
```

```math
\nabla_x L=\nabla_z L\,W^{\mathsf T}
```

这里把 x 看作一行向量。用 `x=[1,2]` 和前面的 logit 梯度，W 的梯度为：

```text
[[ 0.66524, -0.75527, 0.09003],
 [ 1.33048, -1.51054, 0.18006]]
```

再用 x 的梯度更新产生 x 的 Embedding 行。这就是反向传播：不是“猜参数怎么改”，而是沿前向计算图依次使用局部导数。

如果同一个 Token 在一个 batch 中出现多次，它对应的 Embedding 行接收多个位置的梯度，必须求和。NumPy 中普通花式索引赋值容易丢失重复位置的累加，示例使用 `np.add.at` 明确执行累加。

一个 batch 的损失若定义为均值，梯度也要除以样本数；否则扩大 batch 会无意中放大更新量。多个样本长度不一致时，先明确按样本平均还是按有效 Token 平均。

## 7. 一个最小训练循环中各对象的寿命

```text
初始化参数（一次）
重复：
  取一批输入和标签
  前向：计算概率与损失
  反向：计算每个参数的梯度
  更新：按优化器规则修改参数
  清理本轮激活与梯度
保存参数与需要恢复的训练状态
```

参数跨训练步骤保留；激活是这次输入的中间结果；梯度说明本次损失如何受参数影响；优化器状态记录跨步骤的更新历史。它们是不同对象。

`bigram_train.py` 用 SGD；下一课的注意力程序用 Adam。Adam 保留梯度的一阶、二阶滑动平均，并在初始阶段做偏差校正，最后用二阶量缩放更新。它的状态也会占内存。程序没有权重衰减，不能称为 AdamW。

## 8. 如何确认反向传播没有写错

对某个参数做中心差分：

```math
g_{\mathrm{numeric}}\approx\frac{L(\theta+\epsilon)-L(\theta-\epsilon)}{2\epsilon}
```

保持数据和其他参数不变，比较数值梯度与解析梯度。ε 太大引入局部近似误差，太小受浮点舍入影响。教学程序用 float64 和 `1e-5`，从每组参数抽取坐标检查。

这类检查能发现转置、漏除 batch、重复索引梯度丢失等错误。它不证明数据标签正确，也不证明训练目标符合业务目标。

## 9. 练习与解析

**练习 1。** 输入形状 `[8,5,16]`，输出矩阵 `[16,9]`，logits 的形状是什么？softmax 沿哪个维度？

**解析。** `[8,5,9]`，沿最后一个维度。每个样本的每个位置独立得到一个 9 类概率分布。

**练习 2。** 把 `[2,1,0]` 全部加上 100，softmax 是否改变？梯度是否改变？

**解析。** 都不改变。公共平移在归一化中消掉；`p−y` 只依赖概率和真实目标。数值实现仍需减最大值。

**练习 3。** 一个 batch 中 Token 甲出现三次，收到梯度 `[1,0]`、`[0,2]`、`[-1,3]`。其 Embedding 行应收到什么？

**解析。** `[0,5]`，是总和。若损失按 batch 平均，对应平均因子应在计算梯度时一致应用，不能在这里再次重复除。
