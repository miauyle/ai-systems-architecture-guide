# 第 1 课：从计数到预测，明确模型在学习什么

[课程目录](README.md) · [下一课：参数与梯度](02-tensors-and-gradients.md)

本课的目标是把“语言模型会预测下一个 Token”变成可以手算和检验的过程。只用计数、比例和对数，先不使用神经网络。

## 1. 把问题缩小到可以检查对错

假设有四种需要记住的符号：`甲、乙、丙、丁`。另外四个符号只负责干扰，记为 `干扰1…干扰4`，最后统一放一个 `问`。

```text
输入：甲 干扰1 干扰2 干扰1 问    目标：甲
输入：乙 干扰1 干扰2 干扰1 问    目标：乙
```

输入的最后一个符号都是 `问`。完整输入包含答案，最后一个符号却不包含区分答案的信息。这个设计可以分开两个问题：模型是否看到了足够的信息；模型是否学会利用这些信息。

先给每个符号一个编号。`甲…丁` 是 `0…3`，干扰符号是 `4…7`，`问` 是 `8`。例如第一条输入是 `[0,4,5,4,8]`，目标是 `0`。编号只是词表索引，`乙=1` 不意味着乙比甲“多一单位”。

真实 Tokenizer 需要处理任意文本、拆分和词表编码；这里直接指定符号，避免把分词问题与预测问题混在一起。正文中的一个汉字也不必对应真实模型的一个 Token。

## 2. 最简单的模型是一张统计表

设模型只看最后一个 Token。它记录“末尾为 `问` 的样本，下一 Token 分别出现多少次”。我们的训练数据中，每个目标出现 48 次，因此计数是：

| 已观察的上下文 | 目标甲 | 目标乙 | 目标丙 | 目标丁 | 合计 |
| --- | --- | --- | --- | --- | --- |
| 问 | 48 | 48 | 48 | 48 | 192 |

把计数除以总数，每个答案的条件概率都是 `48/192=0.25`。概率向量是 `[0.25,0.25,0.25,0.25]`。

这已经是一个模型：输入当前 Token，查询一行分布，再选一个输出。只看前一个 Token 的条件模型通常称为 bigram 模型。在自然语言中，它能够学到局部相邻关系，但丢掉了远处的信息。

这个任务的测试集也严格均衡。无论总选甲、总选乙，还是按固定概率随机选，都只能在平均意义上猜对四分之一。即使把训练时间增加一万倍，也不能通过相同的输入 `问` 区分四种目标。

这里的 `25%` 上限依赖“只用最后一个 Token”和“均衡分布”两个条件。加入位置、样本编号等旁路可能造成泄漏；测试集不均衡时，总猜最多的类别又会得到不同分数。

## 3. 为什么不能只用准确率训练

假设真实目标是甲，两种预测分别为：

```text
A：[0.40,0.30,0.20,0.10]
B：[0.90,0.04,0.03,0.03]
```

它们的最大值都落在甲，准确率都计为正确。但是 B 给真实答案的概率更高。训练需要一个能反映这种差异的连续量。

对一个真实目标，负对数似然定义为：

```math
L=-\log p(y\mid c)
```

`c` 表示输入上下文，`y` 是真实目标，`p` 是模型输出概率。使用自然对数时，A 的损失为 `-ln(0.4)=0.9163`，B 为 `-ln(0.9)=0.1054`。给错误答案过高的置信度会受到更大惩罚：真实概率 `0.01` 对应损失 `4.6052`。

对多个样本取平均，就得到经验交叉熵损失。它不是“回答好坏”的全部定义，但为参数学习提供了明确、可微的目标。

对于均衡的四选一任务，末尾 Token 模型的最优平均损失是：

```math
L=-\frac14\left(\log\frac14+\log\frac14+\log\frac14+\log\frac14\right)=\log 4\approx1.3863
```

概率分布不能随意全调大，因为四个概率必须相加为 1。若把甲提高到 `0.7`，另外三个各为 `0.1`，平均损失变成 `1.8161`，比均匀分布更差。

神经网络通常对整个词表计算概率。我们的词表有 9 个符号，但只有前四个会作为这个任务的目标。最优分布把几乎全部概率分给这四个目标，最优损失仍趋近 `ln(4)`。softmax 的有限 logits 无法把其余概率严格设为零，但可以无限接近。

## 4. 从一个目标扩展到整段文本

真实语言训练有很多连续目标。例如用字符词表表示：

```text
完整序列：BOS 春 天 花 开 EOS
模型输入：BOS 春 天 花 开
训练目标：春  天 花 开 EOS
```

第一个位置用 `BOS` 预测春，第二个位置用 `BOS 春` 预测天，依此类推。训练同时计算多个位置；每个位置只能看到它自己的历史。后面的答案不能偷看。

如果一条序列由多个 Token 组成，其概率可以按条件概率链式展开：

```math
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_1,\ldots,x_{t-1})
```

第一个位置的历史为空，实际实现常用起始标记。取负对数后，乘积变成各位置损失的和。这就是为什么语言模型可以用许多“给定前缀，预测下一 Token”的样本进行训练。

本课程的记忆任务只监督最后一个预测位置，相当于把其他位置的损失掩掉。它展示条件预测和上下文利用，不宣称覆盖自然语言训练中的全部现象。

## 5. 训练与测试必须回答不同问题

训练样本用于调整模型。测试样本在调整结束后用于检查它是否能处理未参与优化的输入。

我们的干扰符号有 4 种，三个干扰位置共有 `4×4×4=64` 种组合。四个目标合计 `4×64=256` 种输入。每个目标随机选 48 种用于训练，剩余 16 种用于测试：训练 192 条，测试 64 条，没有重复前缀。

这只能测“同一种规则在新干扰组合上是否成立”。不能推出模型理解了中文、能记住任意长文本，或在真实制度问题中可靠。测试要对应声明的能力范围。

如果训练集和测试集直接包含相同输入，高分可能来自记住样本。如果把测试答案放进检索结果或提示，也可能误把泄漏算成推理能力。第四、八课会继续讨论这种区分。

## 6. 动手：观察一个小模型的损失下降

```bash
python examples/bigram_train.py
```

这个程序使用“春天花开”等字符序列，显式计算交叉熵和梯度。它不使用本课的记忆任务，作用是观察最小训练循环；第三课会运行对应的上下文任务。

先记录初始损失和最终损失，再检查“天”之后的分布。花与雨在语料中都出现，所以一个只看天的模型不能把二者同时预测成概率 1。训练损失存在由数据条件分布决定的下界，损失不为零不一定是程序出错。

## 7. 练习与解析

**练习 1。** 某上下文出现 10 次，下一 Token 为甲 8 次、乙 2 次。计数模型应输出什么？总猜甲的准确率与平均交叉熵分别是多少？

**解析。** 输出 `[0.8,0.2]`；总猜甲准确率 `80%`。平均损失为 `-0.8ln(0.8)-0.2ln(0.2)=0.5004`。高准确率与低损失不是同一个指标。

**练习 2。** 在四选一记忆任务中，把模型参数翻十倍，但仍只输入 `问`，能否突破理论上限？

**解析。** 在相同均衡分布和无额外信息的前提下不能。先解决输入信息缺失，再讨论参数容量。模型尺寸增加并不能恢复被输入管道删掉的信息。

**练习 3。** 输入 `BOS 春 天 花` 的四个预测目标是什么？如果“花”已经出现在预测“花”的输入中，会怎样？

**解析。** 正确目标依次是春、天、花及其后一个 Token。预测花的位置只能看到 `BOS 春 天`。若该位置能够直接看到花，训练可以学复制答案，而推理时根本不存在这个答案，形成训练与推理的不一致。

下一课保持同一个预测目标，把“统计表中的概率”换成“矩阵计算出的概率”，并推导怎样更新这些矩阵。专题补充：[Token 与表示](../docs/03-tokenization-and-embeddings.md)、[训练系统](../docs/17-training-engineering.md)。
