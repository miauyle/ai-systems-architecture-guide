# 连续课程：从一个预测问题到可靠的 AI 系统

[返回知识库首页](../README.md)

这条路线把前一课的结果作为后一课的起点。先做一个能检查对错的小模型，再解释完整 Transformer 的结构和训练；随后把模型放进服务，给它连接证据和工具，最后检验整个系统是否可靠。术语在遇到具体问题时引入。

无需先学完高等数学。第一课只需要理解计数和比例；矩阵、导数、链式法则在第二课按实际计算补齐。代码需要基础 Python，运行 NumPy 示例需要安装 NumPy；只阅读不需要安装环境。

## 两个持续演进的例子

**模型侧：记住开头的符号。** 输入 `甲 干扰1 干扰2 干扰1 问`，预测 `甲`；输入 `乙 干扰1 干扰2 干扰1 问`，预测 `乙`。最后一个输入相同，答案却取决于更早的位置。从只看最后一个 Token 的计数模型开始，逐步加入向量、梯度、注意力和完整 Decoder。符号是人工指定的 Token ID，不冒充真实分词器。

**系统侧：差旅制度助手。** 用户先问“上海住宿上限多少”，再要求“帮我提交超标申请”。系统需要选对组织、制度版本、单位和证据，最后确认外部写操作的结果。同一请求贯穿检索、Agent 与评估，所有制度数值都是教学假设。

## 实验的递进关系

在仓库根目录执行：

```bash
python examples/bigram_train.py
python examples/context_attention_train.py
python examples/transformer_numpy.py
python examples/rag_walkthrough.py
python examples/agent_runtime.py
```

1. `bigram_train.py`：最小的参数、损失和梯度循环；单字符上下文。
2. `context_attention_train.py`：所有参数都参与反向传播，训练读取早期上下文；数据有互不重复的训练/测试前缀。
3. `transformer_numpy.py`：完整小型 Decoder 的前向与 KV 缓存；随机权重，用来验证计算，不承担语言任务。
4. `rag_walkthrough.py`：过滤组织和生效日期后检索；不调用 LLM。
5. `agent_runtime.py`：确定性策略和模拟后端验证工具执行、结果未知与对账；不调用真实业务系统。

注意力模型和完整 Decoder 不是同一个训练后的模型。第三个程序验证的是计算等价性，不能把前一个程序的任务准确率写成完整 Transformer 的语言能力。第二、四课会逐项说明实现差异。

## 课程与专题如何配合

先沿课程建立一条完整因果链，再按每课末尾的链接进入 `docs/`。那里保留更细的 RoPE、GQA、MoE、分布式、ANN、规划、记忆、多模态等专题。专题不要求一次读完，也不代替课程的推导和实验。

原始论文与官方资料统一收录在[参考资料](../docs/references.md)。课中给出的尺寸、制度、负载与业务环境都只是明示的教学配置；实际实现需代入自己的配置。
