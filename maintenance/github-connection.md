# 仓库访问与交付边界

[返回首页](../README.md) · [Pages 准备说明](publishing.md)

本页属于仓库维护信息，不是 AI 知识正文。

## 不同权限对应不同动作

读取公开仓库、创建分支与提交、创建 PR、合并 PR、管理 Pages 与部署配置，分别涉及不同的权限。一次读取成功不能证明所有写入或部署动作都可用。

使用当前已有授权与支持的连接，不把凭据写入仓库、远程地址或输出。CLI 与 API 是不同操作方式，不改变应遵守的仓库和用户授权范围。

## PR 交付

仓库为 `miauyle/ai-systems-notes`，唯一长期主线 `master`。修改建立临时分支，提交前检查实际差异和文档链接，再创建 PR。

用户已要求助手自行合并。合并前核对目标主线、文件列表、检查结果与精确 head SHA；主线变化时先整合，不强制覆盖。合并后核对文件与预期一致，并删除本次临时分支。

## 网站部署

主题配置、站点构建和 Pages 部署属于另一条流程。只有实际配置并完成构建与部署，才能报告网站上线。当前尚未进行该流程。
